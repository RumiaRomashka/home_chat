# Home Chat — приватный мессенджер

Self-hosted чат для личного использования: добавляй друзей и близких, чтобы оставаться на связи, 
даже когда популярные мессенджеры заблокированы.

## Описание
Клиент-серверное приложение, монолитная архитектура. 
Позволяет добавлять пользователей по инвайт-ссылке, вести личные и групповые переписки, хранить историю сообщений, 
обмениваться файлами и голосовыми сообщениями.

## Стек
| Слой           | Технологии                    |
|----------------|-------------------------------|
| Backend        | Python, FastAPI, SQLAlchemy   |
| БД / кэш       | PostgreSQL, Redis             |
| Файлы          | MinIO                         |
| Очереди        | RabbitMQ                      |
| Frontend       | React (либо Vue)              |
| Инфраструктура | Docker, docker-compose, Nginx |
| VCS            | Git                           |

## Архитектура (кратко)

```
   Клиент
      │
    Nginx
      │
FastAPI монолит
      │
 ┌────┼────────┬──────────┐
PostgreSQL   Redis   MinIO   RabbitMQ
(данные)   (кэш/сессии) (файлы) (очереди)
```

Всё поднимается через `docker-compose`.
